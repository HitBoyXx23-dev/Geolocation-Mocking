🧑‍💻 How to Use DevTools to Mock Location

  1. Press Shift + Ctrl + I (or Cmd + Option + I on Mac) to open Developer Tools.
  2. Press Shift + Ctrl + P to open the Command Menu.
  3. Type sensors and hit Enter.
  4. Scroll to the bottom panel → Select a predefined location or choose “Custom location.”

💡 You can also use the Console tab to manually mock the geolocation API with the code below.


// Mock getCurrentPosition
navigator.geolocation.getCurrentPosition = function(success) {
  success({
    coords: {
      latitude: 37.7749,
      longitude: -122.4194,
      accuracy: 10
    }
  });
};
console.log("✅ Geolocation overridden to San Francisco");

🧠 Tips & Tricks

  • Use the “Sensors” tab to emulate any city.
  • Use manual input for your own coordinates.
  • Override getCurrentPosition() globally with one click.
