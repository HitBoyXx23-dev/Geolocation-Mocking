How to use the Methods:

  • Click on a location button to simulate `getCurrentPosition()` for a specific city.
  • Click "Override `getCurrentPosition`" to globally mock `getCurrentPosition` to return a fixed location.
  • Click "Override `watchPosition`" to simulate continuous location updates.
  • Use the "Manually Set Location" section to input a custom latitude and longitude.

**Important:** If you're using **DevTools Sensors**, you must enable the "Sensors" tab in Chrome DevTools to simulate geolocation.
